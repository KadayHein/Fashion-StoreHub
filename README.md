Full Stack E-Commerce Platform

A full-stack, multilingual online fashion store built with Next.js, React, MUI, GraphQL, Spring Boot, JPA/Hibernate, and PostgreSQL, deployed using Vercel and Render.

## Tech Stack
Frontend
- NextJS
- TypeScript
- Apollo Client
- MUI

Backend
- Spring Boot
- Spring Security
- GraphQL
- Hibernate

Database
- MySQL

Cloud
- Railway
- Vercel
- Supabase

Features
✔ Login
✔ JWT Authentication
✔ Shopping Cart
✔ Product Search
✔ Order Management
✔ Admin Dashboard
✔ Image Upload
✔ GraphQL API

Architecture
Frontend -> GraphQL -> Spring Boot -> MySQL
